## 💡 Project Overview

**Anti Gravity** is a web application created to demonstrate interactive front-end design and smooth user experience. 

Designed with a sleek, user-centric interface, the project showcases real-time dynamic pricing calculation, modular service configuration, seamless modal flows, and responsive design across desktop and mobile devices.

---

## 🛠️ How I Built It

* **Concept & Design:** Developed with a focus on fluid UI layouts and interactive components.
* **Tech Stack:** Built using HTML5, CSS3, and JavaScript for structuring, styling, and dynamic behaviors.
* **Development Process:** Designed and structured the code layout step-by-step, ensuring responsive design for different screen resolutions.

---

## 🌐 Hosting & Deployment

* **Hosting Platform:** Deployed and hosted live on **Netlify** — [**instaseel.netlify.app**](https://instaseel.netlify.app/).
* **Deployment Workflow:** Linked directly to the GitHub repository for continuous deployment—every update pushed to the repository automatically triggers a live build on Netlify.
* **Data Management:** Operates as a client-side web application handling layout and interactive states directly in the browser.

---

## ✨ Key Features

- **⚡ Fluid UI & Micro-Interactions:** Modern dark aesthetic with glassmorphism, smooth animations, and tactile feedback on interactive buttons and inputs.
- **📱 Fully Responsive Design:** Custom-tailored layouts optimized for mobile smartphones, tablets, laptops, and ultra-wide desktop monitors.
- **🔄 Real-Time State & Price Calculator:** Instant calculations for custom quantities, tiers, and regional pricing models without latency or page reloads.
- **🌍 Multi-Region & Multi-Store Architecture:** Dedicated regional portals (India and USA stores) offering tailored currency rates and localization.
- **🛡️ Secure Client-Side Architecture:** Zero-dependency vanilla JavaScript foundation ensuring lightweight bundle sizes, lightning-fast first contentful paint (FCP), and high Lighthouse scores.
- **📊 Admin Management Console:** Dedicated administration portal integrated with Firebase for service catalogue oversight and order records.
- **🚀 Continuous Integration & Delivery (CI/CD):** Integrated with Netlify edge hosting for automated builds, instant rollbacks, and SSL management.

## 📖 Usage Guide

1. **Browse Services:** Explore available services and packages on the main landing interface.
2. **Configure Order:** Select desired tiers and adjust quantities—the dynamic calculator will update pricing in real time.
3. **Regional Switcher:** Access regional versions (e.g., USA portal) via dedicated navigation links.
4. **Order Confirmation:** Fill in your details in the modal checkout flow to review order specifications.
